# Ilmvers Institute

Online portal for Qur'an, Tajweed, and Islamic Studies. Setup and the remaining keys are in [SETUP.md](SETUP.md). What is already built is listed in [PARITY-STATUS.md](PARITY-STATUS.md).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

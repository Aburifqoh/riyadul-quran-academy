# RiyaduAlQuran Academy Website

This is a multi-page static website built to replicate the design and structure of `alwaduudinstitute.com`.

## Features
- **Design System**: Exact colors (#0c4c3d, #dfa616) and typography (Amiri, Inter).
- **Responsive**: Fully optimized for mobile, tablet, and desktop.
- **Animations**: Smooth fade-up animations on scroll.
- **Components**: Sticky navbar, testimonial carousel, stats counter (visual), and contact form.
- **Standalone**: Every page is a standalone `.html` file using Tailwind CSS via CDN.

## File Structure
- `index.html`: Home page with hero, intro, subjects, and stats.
- `about.html`: Academy mission and background.
- `courses.html`: Detailed list of subjects and curriculum.
- `video-gallery.html`: YouTube integration and visual gallery.
- `achievements.html`: Milestones and student reach.
- `blog.html`: News and Islamic insights.
- `contact.html`: Contact form and academy location/details.
- `assets/images/`: Placeholder for your official logo and feature images.

## Customization
1. **Logo**: Replace `assets/images/logo.jpg` with your official logo.
2. **Images**: Update the `src` attributes in the HTML files to point to your real images.
3. **Contact Details**: Update the phone number and email in the Top Bar and Footer of each page.
4. **Forms**: The contact form is frontend-only. You can connect it to a service like [Formspree](https://formspree.io/) for email notifications.

## How to Run
Simply open `index.html` in any web browser.

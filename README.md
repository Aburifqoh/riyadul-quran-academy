# Riyadul Quran Academy

A premium, modern multi-page static website for **Riyadul Quran Academy**, specializing in Qur'an Memorization, Arabic, and Islamic Studies.

## ✨ Premium Features
- **Modern Aesthetic**: A high-end design featuring a sophisticated teal and gold color palette.
- **Elegant Typography**: Utilizing *Playfair Display* for classic headings and *Inter* for clean, modern body text.
- **No-Human Imagery Policy**: All visual assets are strictly non-animate, featuring beautiful Islamic architecture, calligraphy, and academic photography.
- **Mobile First**: Fully responsive layout optimized for smartphones, tablets, and desktops.
- **Interactive Elements**:
  - Floating WhatsApp integration for direct student inquiries.
  - Smooth fade-up scroll animations (Intersection Observer).
  - Glassmorphism navigation effects.
  - Responsive mobile menu.

## 📁 Project Structure
- `index.html`: Home page with hero section, subjects overview, and academy stats.
- `about.html`: Our mission, vision, and educational philosophy.
- `courses.html`: Comprehensive curriculum including Tajweed, Hadith, Fiqh, and Arabic.
- `video-gallery.html`: Visual showcase of academy activities.
- `achievements.html`: Tracking our growth and student success.
- `blog.html`: Educational insights and academy news.
- `contact.html`: Registration portal and contact details.
- `assets/`: 
  - `images/`: Logo and local image assets.
  - `js/`: Core logic for animations and menu interaction.

## 🚀 Deployment
This is a static website. To deploy:
1. Upload all files to any static hosting service (GitHub Pages, Netlify, Vercel).
2. Ensure the `assets/` folder is included in the root directory.
